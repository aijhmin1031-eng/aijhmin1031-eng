### Radiation Lab

I build free, browser-based tools for radiation science and engineering at
**[radiation-lab.com](https://radiation-lab.com/)**. Nothing to install; every
calculation names the standard or model it implements.

- **[RadCalc](https://radiation-lab.com/calc/)**: dose rate with attenuation and
  buildup, gamma shielding, beta range, detection limits (MDA), decay, and
  [147 nuclide reference sheets](https://radiation-lab.com/calc/nuclides/).
  Open source ([radiation-calc](https://github.com/aijhmin1031-eng/radiation-calc)),
  [validated](https://radiation-lab.com/calc/validation/) against published cases.
- **[RadiMeter](https://radiation-lab.com/radimeter/)**: performance-test
  worksheets for radiation measuring instruments under IEC 60846-1, 60532, 60325,
  61005 and 61017.
- **[M-Phreefiteq](https://radiation-lab.com/disposal/)** (beta): radionuclide
  migration through the geosphere, built on PHREEQC.
